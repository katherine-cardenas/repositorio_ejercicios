# Repositorio de ejercicios

Este repositorio contiene una colección de ejercicios prácticos en HTML y CSS, diseñados para reforzar conceptos de maquetación, formularios, tablas, diseño responsive y uso de datos en páginas web.

## Descripción

El proyecto incluye varios ejemplos HTML independientes que muestran diferentes técnicas de desarrollo front-end, como:

- Cuadriculas y distribución visual
- Presentación de datos
- Diseño con columnas
- Formulario de contacto
- Tablas y estructura de contenido
- Página de inicio con acceso a los ejercicios

## Estructura del proyecto

- `index.html` — página principal con enlaces a los ejercicios
- `ejercicio_cuadriculas.html` — ejercicio sobre cuadriculas y alineación
- `ejercicio_datos.html` — presentación de información y datos
- `ejercicio_diseño_columnas.html` — maquetación con columnas
- `ejercicio_formulario.html` — formulario HTML con estilos básicos
- `ejercicio_tablas.html` — ejemplo de tablas y estructura de contenido
- `img/` �� recursos gráficos del proyecto

## Cómo visualizar el proyecto

1. Clona este repositorio.
2. Abre cualquiera de los archivos `.html` en tu navegador.
3. También puedes abrir `index.html` como punto de entrada para navegar entre los ejercicios.

## Tecnologías utilizadas

- HTML5
- CSS
- Diseño web estático

## Objetivo

Practicar y consolidar conocimientos de maquetación web utilizando HTML y CSS, con ejercicios simples pero funcionales.
